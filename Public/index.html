Primary REST API Endpoints

Secure JSON endpoints protected via JWT cookies, rate limiting, and CSRF tokens.

GET /api/v1/healthcheck
System heartbeat, uptime, and database telemetry
GET /api/v1/videos
Fetch filtered, paginated video feed & search results
POST /api/v1/users/login
Account authentication & cross-domain JWT issuance
GET /api/v1/videos/:videoId
Stream resolution details, owner metadata, and viewer stats
POST /api/v1/likes/toggle/v/:videoId
Atomic video like / dislike state toggle
GET /api/v1/comments/:videoId
Paginated comments stream & nested replies tree
